# Bharat Energy AI — NILM Platform

> **Non-Intrusive Load Monitoring** powered by 5 simultaneously-running ML models.  
> Real-time appliance disaggregation · Demand forecasting · Anomaly detection · Grid intelligence

---

## Overview

Bharat Energy AI is a full-stack research platform that performs **Non-Intrusive Load Monitoring (NILM)** on a single aggregate power-consumption signal and disaggregates it into per-appliance contributions — without any hardware sensors on individual devices. The system is built for three user personas (Consumer, Industrial facility, DISCOM grid operator) and a Research dashboard, all driven by a shared FastAPI inference backend.

## ML Models

| # | Model | Task | Algorithm | Key Features |
|---|-------|------|-----------|--------------|
| 1 | **Random Forest** | Appliance classification | `sklearn` RF (150 trees, depth 12) | aggregate, Δ, hour, roll_mean5, roll_std5 |
| 2 | **XGBoost** | Next-step load forecast | `xgboost` XGBRegressor (200 trees) | same 5 features, target = aggregate(t+1) |
| 3 | **Logistic Regression** | Anomaly detection | `sklearn` Pipeline (StandardScaler + LR) | aggregate, Δ, roll_std5 |
| 4 | **Gaussian HMM** | Regime detection | `hmmlearn` GaussianHMM (3 states) | aggregate reshaped as observation |
| 5 | **LSTM** | Sequence load forecast | PyTorch 2-layer LSTM (hidden=64) | MinMax-normalised seq of 24 readings |

All 5 models are loaded once at startup inside `InferenceEngine` and called on every request via a shared `.predict()` method that maintains rolling buffers for stateful features (delta, rolling mean/std, LSTM sequence window).

## Dataset

- **Source**: Synthetic UK-DALE-style data generated by `training/generate_dataset.py`
- **Size**: 8 000 rows at 1-minute resolution (~5.5 days)
- **Appliances**: `geyser`, `ac`, `washing_machine`, `tv`, `fridge`
- **Features injected**: time-of-day patterns, weekday/weekend shifts, Gaussian noise, 2% anomaly spikes (3.5× multiplier)
- **Label**: dominant appliance (highest draw) per timestamp
- **Columns**: `timestamp`, `aggregate`, `label`, `is_anomaly`, `ch_<appliance>` (5 channel columns)

## Development Timeline

### Phase 1 — Data & Model Foundation
- Designed `generate_dataset.py` with realistic appliance profiles (active windows, Gaussian noise, anomaly spikes)
- Trained RF classifier, XGBoost forecaster, Logistic Regression anomaly detector, Gaussian HMM
- Trained PyTorch LSTM with proper MinMax normalisation, DataLoader batching, gradient clipping, LR scheduling

### Phase 2 — Inference Engine
- Built `InferenceEngine` with unified `.predict()` API
- Implemented stateful rolling buffers (delta, roll_mean/std, LSTM seq-24 window)
- Added `.reset()` for clean batch sessions

### Phase 3 — FastAPI Backend
- Mounted all endpoints in `app.py` with CORS, global state management
- Built SSE streams (`/infer/stream`, `/phone/stream`) for real-time UI updates
- Added batch CSV inference with flexible column detection
- Implemented smart-plug router (`devices.py`) with per-tick energy simulation and scheduling

### Phase 4 — Frontend Dashboards
- Built Next.js app with 5 role-specific dashboards
- Integrated Recharts, Nivo (Sankey, Heatmap), React Three Fiber (3D house scene)
- Added `NotificationContext` for cross-dashboard alerts, `GlobalNav` for routing
- Implemented ToU band scoring, occupancy inference, duty cycle, vampire-load breakdown

### Phase 5 — Advanced Analytics
- Grid dashboard: NTL theft localisation with K-Means cluster scoring, credibility decay, Z-score ranking
- F1 drift monitoring: 30-day rolling per-class F1 with seasonal injection (AC degrades in summer)
- Industrial: THDi per-phase with CBIP/CEA limits, demand charge calendar heatmap, shift-wise intensity
- Consumer: reactive/apparent power breakdown per appliance, nudge engine, smart alarms

## Quick Start

### Backend
```bash
cd backend
pip install fastapi uvicorn torch scikit-learn xgboost hmmlearn pandas numpy joblib
python training/generate_dataset.py
python training/train_rf.py
python training/train_gb.py
python training/train_logreg.py
python training/train_hmm.py
python training/train_lstm.py
uvicorn app:app --host 0.0.0.0 --port 8000 --reload
```

### Frontend
```bash
cd frontend
npm install
npm run dev   # http://localhost:3000
```
